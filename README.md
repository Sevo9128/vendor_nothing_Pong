# Vendor for Nothing Phone 2 (Pong)
##### Lineage 23.0+23.1 branch - Required for build

## Setup

Clone the correct branch into **vendor/nothing/Pong**

You can do so by selecting the branch corresponding to your rom at the top and executing this command:
> git clone https://github.com/Sevo9128/vendor_nothing_Pong.git -b lineage-23.0+23.1 vendor/nothing/Pong


## Other

Get everything needed to build a custom rom for Pong at [my collection](https://github.com/Sevo9128/nothing-Pong-dev-collection)
